## Track

**Professional Agents**

## Project description

FairChange is an evidence-backed change-resolution agent for implementation consultants. It compares a client request with signed scope, correspondence, and delivery tasks, then classifies it as a defect, included revision, or scope change while preserving a human approval gate for commercial changes. The project demonstrates restart-safe intake, traceable evidence, and an Amazon Bedrock AgentCore runtime using synthetic fixtures.

## Short version

FairChange helps implementation teams decide whether a client request is a defect, included revision, or paid scope change using evidence from scope, correspondence, and delivery tasks. It produces a traceable decision and keeps commercial changes behind owner authorization and exact client acceptance.
