## Track

**Professional Agents**

## Project description

FairChange is an evidence-backed change-resolution agent for implementation consultants. It automates the repetitive evidence hunt across signed scope, correspondence, and delivery tasks, then classifies a request as a defect, included revision, or scope change and explains the next safe action. Commercial changes remain behind owner authorization and exact client acceptance, while the public workspace gives judges a clear, interactive walkthrough of the product. The project demonstrates restart-safe intake, traceable evidence, and an Amazon Bedrock AgentCore runtime using synthetic fixtures.

## Short version

FairChange helps implementation teams decide whether a client request is a defect, included revision, or paid scope change using evidence from scope, correspondence, and delivery tasks. It removes the repetitive search while keeping the commitment with humans: owners authorize a proposal and clients accept the exact version before work begins.
